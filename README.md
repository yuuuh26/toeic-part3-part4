# Listening Studio — TOEIC Part 3・Part 4

Android Chrome向け、前置きなしで反復できる個人用PWA。非公式のオリジナル教材です。

## 収録内容

- Part 3：6セット・18問。男女／同性2人／3人会話。
- Part 4：6セット・18問。
- 全セットに事前生成MP3、日本語訳、設問解説、重要表現。
- 英米の男女4音声。1セット1本、64kbps・mono。

## 使い方

1. Partと出題対象を選び「練習をはじめる」。即開始が初期設定です。
2. 音声を聞きながら3問に回答し、「まとめて採点」。回答だけでは音声は止まりません。
3. 正誤と解説を確認し、必要なら全文・訳を開く。次のセットへ進めます。
4. ホームの「問題パック・オフライン保存」でパックを音声ごと保存します。
5. オンラインで一度開き直してからオフライン利用します。
6. Android Chromeのメニューから「ホーム画面に追加／アプリをインストール」。

端末の自動再生制限にかかった場合は「再生」を1回タップしてください。

## 保存・通信

- 履歴は IndexedDB `yuu-listening-studio`。セット単位のトランザクションで3問を保存。
- 同じ採点の保存再試行は重複せず、別の練習は別の履歴になります。
- 未回答のまま採点した設問は誤答として記録されます。
- 「間違えた問題」は最新回答が不正解の設問を含むセット。「未回答」は履歴のない設問を含むセット。
- 通常の学習に音声生成API、分析サービス、ログイン、クラウド履歴送信を使いません。
- 初回読込とパック保存は配信元に通信します。端末保存後はネットなしで使用できます。
- 起動時はカタログとUIだけ。選択したPartのJSONを読み、音声は現在＋次の最大2セットを準備。
- 永続保存はブラウザの裁量です。許可されなくても通常保存を継続します。
- noindexはアクセス制御ではありません。公開リポジトリの教材は公開情報です。

## 問題の追加

詳しくは [ADDING_QUESTIONS.md](ADDING_QUESTIONS.md)。`JSON + MP3 + data/catalog.json` の追記で追加できます。アプリのJavaScript変更は不要です。

問題数は1セット3問単位です。50問追加なら17セット51問など、セット数で調整してください。

## 開発・検証

```sh
python3 -m http.server 8000
python3 scripts/validate.py
npm install
npm test
```

音声の再生成は作成時だけ実行します（ffmpegとネット接続が必要）。既存MP3は通常スキップします。

```sh
python3 -m pip install edge-tts==7.2.8
python3 scripts/generate_audio.py
```

`--force`は既存音声も意図的に作り直す場合のみ指定してください。

## 更新時の注意

- 問題・設問IDは不変。意味が変わる修正は新しいIDにします。
- IndexedDBを削除しないでください。スキーマ変更はonupgradeneeded内で非破壊に行います。
- UI/JS/CSSを更新するときは service-worker.js のSHELL版を上げます。
- Service Workerは新しい版のインストール後、旧タブを閉じて再起動すると更新します。学習中の強制切替はしません。
- パックキャッシュと他アプリのキャッシュは削除しません。既存音声は別パスで改訂するか保存し直してください。
- `scripts/create_initial_data.py` は初期データの原稿です。パック拡張後は不用意に再実行しないでください。

## 確認範囲

コードの自動テストは、パック追加、固有ID、誤答抽出、IndexedDBの再保存・再接続・履歴保持、Service Worker更新時のキャッシュ保護、オフライン音声のRange応答を対象にしています。

Android実機の音声品質・ホーム画面追加・開始時間0.2〜0.5秒は実機確認が必要です。配信速度、端末、ブラウザの自動再生制限によって変わり、保証値ではありません。
